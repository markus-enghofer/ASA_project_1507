## Rikshaw

### Data Collection

Data was collected using the AgileX LIMO PRO robot mounted on an auto-rikshaw while driving within Mysuru for around 5 minutes. The position of the robot was not fixed rigidly, but it was placed in its box, such that movement of the robot relative to the vehicle should have been minimal. Moreover, the orientation of the robot with respect to which the gyroscope data is provided adheres to the orientation of the auto-rikshaw. Hence, no coordinate transformation was required. The data is divided into three frames. Each of them covers one to three minutes of the ride. Labels for potholes and speedbreakers were recorded manually.
