# Data-Analytics
Analytics of data about road anomalies collected by AgileX robot and mobile phone

This repository provides a basic exploratory analysis of sensor data about road conditions in Mysuru. The underlying dataset contains three parts:
- data collected by AgileX LIMO PRO robot by moving on road
- data collected by AgileX LIMO PRO robot while being mounted in a driving auto-rikshaw
- data collected by iPhone 12 while being mounted in a driving auto-rikshaw

The folders of this repository correspond to these three different collections of data and are named "agilex", "rikshaw" and "smartphone", respectively. As different kinds of sensor data are available depending on the method of data collection, data analysis was performed mostly individually for each of these datasets. More detailed information about the considered data, the methods and the results of each analysis are described in the respective folders.
